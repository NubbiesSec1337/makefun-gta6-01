Palm City Heat is an open-world crime game that runs in the browser — steal cars, outrun the police, pull heists across Leonida. Dual protagonists Lucia & Jason, a 440×440 m city with traffic and pedestrians, a 0–6 star wanted level with police chases and a helicopter, 11 story missions, a weapon wheel, night mode, and the Leonida Social phone feed. Built with three.js, no build step, no network.

## Run it

```sh
node serve.ts  # then open http://localhost:8080
```
